这篇是给刚下载马老师专属去广告、不知道从哪下手的人写的。工具本身是 Windows 上的桌面客户端，插上数据线连上手机，在电脑上点几下，就能关掉国产安卓手机里的系统广告、热搜、资讯推荐和营销推送。不用 root，不用解锁，不用刷机，改动都能还原。

下载地址在文末，着急的人可以直接拉到最后下载，先看完再动手也不迟。

### 这个工具能关掉什么

- 系统广告：个性化广告、广告跟踪、智能推荐服务这些系统设置里的开关
- 热搜和资讯：下拉搜索的热榜、负一屏资讯、浏览器信息流
- 推广位：应用商店的轮播、开屏、悬浮活动、签到福利
- 营销推送：各 App 的内容与营销、活动优惠这类通知渠道
- 快应用：广告链接一点就跳进去的免安装小程序
- 广告组件：OPPO 广告服务、小米系统广告组件这类东西，挂起处理，可以恢复

![关掉前后的手机示意](/images/malaoshi-adcleaner-clean.jpg)

### 动手之前先说清楚，什么不会动

- 下拉搜索、负一屏卡片、应用商店的安装和更新、天气预警、快递提醒，这些正常功能保留
- 不卸载、不停用系统应用，不改 system 分区
- 不替你同意任何用户协议，遇到协议页、权限申请，点取消、以后再说、不允许
- 不截账号页和手机号页
- 系统更新和保修不受影响

### 准备

- 一台 Windows 10 或者 Windows 11 的电脑，64 位
- 一根能传数据的数据线，只充电的线不行
- 手机上打开开发者模式和 USB 调试，客户端里有五个品牌的图文教程，照着开就行

几个品牌要多注意一句：

- 小米和 Redmi 还要打开开发者选项里的 USB 调试（安全设置），这个要插 SIM 卡、登录小米账号
- 荣耀和华为要打开仅充电模式下允许 ADB 调试
- 三星要装三星 USB 驱动
- 电脑上退掉手机助手和安卓模拟器，它们会抢连接

### 在客户端里走一遍

客户端里的流程是这样一条线：连接手机 → 检测 → 选择 → 执行 → 完成。下面按这条线讲。

![电脑连手机示意](/images/malaoshi-adcleaner-connect.jpg)

### 连接手机

- 手机打开开发者模式和 USB 调试
- 数据线连上电脑，手机通知栏里 USB 用途选传输文件
- 手机弹窗问允不允许 USB 调试，勾上始终允许再点允许
- 客户端认出手机，显示型号和系统版本，就可以往下走

客户端认不出来，先按这几条查：换一根能传数据的线；USB 用途改成传输文件；手机弹窗有没有点允许；荣耀和华为看仅充电模式下允许 ADB 调试开了没有；三星看驱动装了没有；电脑上的手机助手和模拟器退了没有。

### 检测

检测这一步是只读的，不改任何东西。客户端读型号、系统版本、机型脚本、快应用和广告组件的状态，列出来给你看。

有机型脚本的手机，检测完直接匹配上对应的脚本。没有机型脚本的手机，走通用部分，再对照同品牌的清单手动处理，清单在仓库 docs/清单/ 里。

### 选择

- 营销通知按渠道列出来，服务类渠道默认不勾，订单、物流、聊天通知、天气预警这些都保留
- 快应用和广告组件关不关，由你自己定
- 挂起广告包这一步要机主点头，客户端会先问你
- 有一类开关不用担心方向拨反：名字以限制、防止、阻止、禁止、关闭开头的保护类开关，打开才是保护，客户端拨的时候就是往开的方向拨

### 执行

动手之前，客户端先存一份改动前的快照，存在 backups/ 里。执行的时候显示进度和实时日志，手机放一边别动。

中途手机锁屏了也不用慌，客户端会等你解锁后继续，不会整步失败。手机断开会报错提示，不会每一步重复报错。

### 完成和还原

执行完列出每一步的结果，核对一遍。收尾记得关闭开发者模式，关掉开发者模式不会撤销这次的改动。

想恢复，客户端左下角有还原改动：恢复快应用、恢复挂起的广告组件、重新打开关掉的营销通知。App 里面的开关要按清单路径手动打开，客户端里有路径。

### 关完还剩什么

有几样要提前说清楚，免得你觉得没关干净：

- 浏览器搜索框的轮播热词没有开关，关不掉
- 新装的 App 自带广告跟踪和营销通知，装新 App 后再跑一次客户端
- 其他 App 自己的开屏广告不在这个工具的范围里

### 反馈和新机型

遇到问题，或者你的机型不在表里，客户端左下角点反馈问题，会自动附上客户端版本、手机型号、系统版本和近期日志，序列号已经替换掉，不含应用列表和通知内容，提交需要 GitHub 账号。也可以直接去仓库提 Issue。

除了桌面客户端，这个项目还有另外三种用法：AI 智能体替你跑、聊天 AI 带你点、照清单手动关，仓库里都有对应的文档，地址是 https://github.com/jason6668/m-teacher-adcleaner 。
