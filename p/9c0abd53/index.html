全平台代理客户端与订阅转换工具使用教程

全平台代理客户端与订阅转换工具使用教程：每个工具怎么安装、导入订阅和排查问题

上一篇文章整理了 Windows、macOS、Linux、Android、iOS 常见代理客户端和订阅转换工具。这一篇更偏向实操，重点讲每一个工具怎么用，包括下载安装、导入配置、开启代理、更新订阅和常见问题处理。

本文只介绍工具使用方法，不推荐任何服务商，也不提供节点购买建议。工具清单参考自 dingyue-tools 项目，该项目说明中提到，工具覆盖 Windows、macOS、Linux、Android、iOS，并且下载链接主要指向官方 GitHub Releases 或 App Store，以降低下载到假冒安装包的风险。(GitHub)

一、使用前准备

在开始之前，你需要准备三样东西：

  1. 一个对应系统的客户端；
  2. 一个可用的订阅链接、配置文件或手动节点信息；
  3. 一个能正常访问下载页面的网络环境。

常见导入方式有三种：

  • 订阅链接导入；
  • 本地配置文件导入；
  • 二维码或手动添加节点。

如果你手里的订阅格式和客户端不兼容，就需要使用订阅转换工具。原项目也把订阅转换工具单独列为一类，用来解决 Clash、Mihomo、Sing-box、Surge、Quantumult X、Loon 等格式之间不兼容的问题。(GitHub)

二、订阅转换工具教程

1. subconverter 使用教程

subconverter 是经典订阅转换工具，适合把一种订阅格式转换成另一种客户端可识别的格式。它的官方说明中写明支持 Clash、Quantumult X、Loon、SS、SSR、Surge、V2Ray 等多种格式作为源或目标格式，并提供了接口形式的转换方法。(GitHub)

适合谁用

适合需要多格式转换、多订阅合并、自建转换服务的人。不太适合完全不想接触参数的新手。

基础使用流程

第一步，打开 subconverter 项目页面。

第二步，根据自己的系统下载 Releases 中对应版本。如果你只是普通用户，更推荐使用已经部署好的前端或服务端；如果你有服务器，可以自行部署。

第三步，准备你的原始订阅链接。

第四步，选择目标格式。例如：

  • Clash / Mihomo 客户端：选择 clash
  • Quantumult X：选择 quanx
  • Loon：选择 loon
  • Surge：选择 surge
  • V2Ray：选择 v2ray

第五步，生成转换后的订阅链接，再复制到目标客户端中导入。

常见问题

如果转换后无法导入，优先检查三点：

第一，原订阅链接是否有效。

第二，目标格式是否选错。

第三，订阅链接是否正确编码。

多个订阅合并时，不建议一次性放太多来源，先用一个订阅测试成功，再逐步增加。

2. Sub-Store 使用教程

Sub-Store 是高级订阅管理器，适合 Quantumult X、Loon、Surge、Stash、Shadowrocket 等用户。原项目介绍中也提到，Sub-Store 支持多订阅聚合、规则处理、格式转换和定时更新等功能。(GitHub)

适合谁用

适合 iOS、macOS 深度用户，尤其是需要统一管理多个订阅、多个客户端配置的人。

基础使用流程

第一步，打开 Sub-Store 项目页面。

第二步，按项目说明部署或使用已有面板。

第三步，进入 Sub-Store 管理界面。

第四步，新建订阅，把原始订阅链接粘贴进去。

第五步，选择输出类型，例如 Clash、Surge、Loon、Quantumult X、Stash 等。

第六步，保存后复制生成的新订阅链接。

第七步，把新订阅链接导入对应客户端。

使用建议

Sub-Store 不只是转换工具，更适合长期管理订阅。你可以用它做节点筛选、重命名、分组、规则处理和定时更新。

新手第一次使用时，建议只做一件事：把一个原始订阅转换成一个目标客户端订阅。等确认能用后，再研究高级脚本和规则。

常见问题

如果生成的链接导入失败，先不要改复杂脚本。先测试最基础的转换流程：

原订阅链接 → Sub-Store → 生成目标订阅 → 客户端导入。

如果基础流程成功，再逐步添加规则处理。

3. Hiddify Next 使用教程

Hiddify Next 是跨平台客户端，支持 Windows、macOS、Linux、Android、iOS。原项目介绍中提到，它基于 Sing-box 内核，支持多平台、多协议、TUN 模式、远程配置文件和内置测速等功能。(GitHub)

适合谁用

适合新手、多设备用户，以及想要一个客户端解决大部分配置问题的人。

Windows / macOS / Linux 安装

第一步，打开 Hiddify Next Releases。

第二步，下载与你系统对应的安装包：

  • Windows 通常选择 .exe 或 .msi
  • macOS 通常选择 .dmg
  • Linux 可选择 .AppImage、.deb 或其他对应格式

第三步，安装并打开软件。

第四步，首次打开时，按系统提示允许网络权限或 VPN 权限。

Android 安装

第一步，打开 Hiddify Next Releases。

第二步，下载 Android APK。

第三步，安装 APK。如果系统提示“禁止安装未知来源应用”，需要在系统设置里允许当前浏览器或文件管理器安装应用。

第四步，打开 Hiddify Next，允许创建 VPN 配置。

iOS 安装

iOS 用户可以通过 App Store 或项目提供的方式安装。若 App Store 地区无法搜索到，需要检查 Apple ID 地区。

导入订阅

打开 Hiddify Next 后，一般可以通过以下方式导入：

  • 粘贴订阅链接；
  • 扫描二维码；
  • 导入配置文件；
  • 从剪贴板识别配置。

导入成功后，先进行一次测速，再选择延迟较低的节点连接。

使用建议

新手建议先使用默认模式，不要一开始就改 DNS、TUN、高级路由等选项。如果能正常使用，再逐步调整规则和分流设置。

常见问题

如果连接后没有效果，检查：

  • 是否允许 VPN 权限；
  • 是否开启系统代理或 VPN 模式；
  • 节点是否测速正常；
  • 订阅是否已经过期；
  • 是否被其他代理软件占用了端口。

4. sing-box-converter 使用教程

sing-box-converter 是偏向 Sing-box 配置转换的工具，适合把其他格式转成 Sing-box 可用配置。

适合谁用

适合主要使用 Sing-box、Hiddify Next、Karing 或其他 Sing-box 前端的用户。

基础使用流程

第一步，打开 sing-box-converter 项目页面。

第二步，查看项目 README 的使用方式。

第三步，准备原始配置或订阅链接。

第四步，按照工具要求输入源配置。

第五步，生成 Sing-box JSON 配置。

第六步，把生成的配置导入 Sing-box 或支持 Sing-box 的客户端。

使用建议

如果你只是新手，不建议直接手写复杂 JSON。可以先用 Hiddify Next 或 Karing 这类图形客户端导入订阅，等熟悉后再尝试单独转换配置。

常见问题

Sing-box 配置对 JSON 格式要求较严格。如果导入失败，常见原因是：

  • JSON 格式错误；
  • 缺少必要字段；
  • 协议字段不兼容；
  • DNS 或路由配置写错。

5. v2sing 使用教程

v2sing 主要用于把 V2Ray 或 Clash 相关配置转换为 Sing-box 配置。

适合谁用

适合已经有 V2Ray、Clash、Mihomo 配置，但想迁移到 Sing-box 的用户。

基础使用流程

第一步，打开 v2sing 项目页面。

第二步，按照 README 准备运行环境。

第三步，输入原始订阅或配置。

第四步，选择输出为 Sing-box 配置。

第五步，把输出配置保存为 JSON 文件。

第六步，在 Sing-box 或支持 Sing-box 的客户端中导入该配置。

使用建议

v2sing 更适合有一定动手能力的人。如果只是日常使用，优先考虑图形客户端；如果你在做配置迁移、批量转换或自定义配置，v2sing 会更合适。

三、跨平台客户端教程

6. Clash Verge Rev 使用教程

Clash Verge Rev 是 Windows、macOS、Linux 上常见的 Mihomo 图形客户端。原项目说明中提到，它支持规则分流、订阅管理和内核切换。(GitHub)

安装方法

第一步，打开 Clash Verge Rev Releases。

第二步，按系统下载：

  • Windows：下载 .exe 或 .msi
  • macOS：下载 .dmg
  • Linux：下载 .AppImage、.deb 或 .rpm

第三步，安装并打开软件。

第四步，首次运行时按提示允许网络权限。

导入订阅

打开软件后，进入 Profiles 或配置页面。

点击 New / Import / 添加配置。

粘贴订阅链接。

点击保存并更新。

选择刚刚导入的配置文件。

启动代理

导入配置后，打开系统代理开关。

选择 Rule 模式作为日常使用模式。

在 Proxies 页面选择策略组和节点。

测试网页是否正常访问。

常见问题

如果导入后没有节点，可能是订阅格式不兼容，可以先用 subconverter 转成 Clash/Mihomo 格式。

如果系统代理开启后浏览器没效果，检查浏览器是否安装了其他代理插件。

7. Mihomo Party 使用教程

Mihomo Party 是简洁型 Mihomo 客户端，适合喜欢轻量操作的人。

安装方法

打开 Mihomo Party Releases，下载对应系统安装包并安装。

Windows 用户选择 .exe 或 .msi。

macOS 用户选择 .dmg。

Linux 用户选择适合自己发行版的包。

导入订阅

进入配置或订阅页面。

点击添加订阅。

粘贴订阅链接。

点击更新订阅。

确认节点列表已经出现。

启动使用

开启系统代理。

选择规则模式。

进入节点页面选择可用节点。

进行延迟测试，优先选择延迟稳定的节点。

常见问题

如果订阅更新失败，先检查链接是否完整，再检查本地网络是否能访问订阅地址。

如果节点延迟全部超时，可以换网络环境测试，也可以检查防火墙是否拦截。

8. FlClash 使用教程

FlClash 是 Fluent UI 风格的 Clash/Mihomo 客户端，原项目说明中提到它支持 Windows、macOS、Linux、Android，并且界面比较现代。(GitHub)

安装方法

打开 FlClash Releases。

根据设备下载对应版本。

桌面端按普通软件安装。

Android 下载 APK 后安装。

导入订阅

进入配置页面。

点击添加配置或添加订阅。

粘贴订阅链接。

更新订阅。

切换到该配置。

启动代理

开启代理服务。

选择规则模式。

进入代理组选择节点。

测试连接。

使用建议

FlClash 界面比较直观，适合新手。Android 用户如果经常断开，建议关闭系统对 FlClash 的电池优化。

9. Karing 使用教程

Karing 是多平台代理客户端，原项目中提到它支持 Windows、macOS、Linux、Android、iOS，并且支持 Clash / Sing-box 前端和多平台配置同步。(GitHub)

安装方法

桌面和 Android 用户可以打开 Karing Releases 下载。

iOS 用户可以通过 Karing App Store 安装。

导入订阅

打开 Karing。

进入配置或订阅管理。

选择添加订阅。

粘贴订阅链接。

点击更新。

选择默认策略组。

多设备同步建议

如果你在多台设备上使用 Karing，可以先在一台设备上配置好订阅、规则和策略，再研究同步功能。不要一开始就在多台设备同时修改配置，容易混乱。

常见问题

如果 iOS 无法下载，检查 App Store 地区。

如果 Android 后台断开，检查电池优化和 VPN 常驻权限。

如果桌面端无法接管流量，检查系统代理是否开启。

四、Windows 客户端教程

10. V2RayN 使用教程

V2RayN 是 Windows 上常见的 V2Ray 系客户端，适合使用 VMess、VLESS、Trojan 等配置的用户。原工具清单也把 V2RayN 列为 Windows 平台常见客户端。(GitHub)

安装方法

打开 V2RayN Releases。

下载压缩包或安装包。

解压后运行主程序。

如果提示缺少运行库，按项目说明安装对应运行环境。

导入订阅

打开 V2RayN。

找到订阅分组或订阅设置。

添加订阅地址。

点击更新订阅。

节点出现后，选择一个节点。

启动代理

右键系统托盘图标。

选择系统代理模式。

通常新手可以选择“自动配置系统代理”。

再选择一个可用节点作为活动服务器。

常见问题

如果浏览器没有走代理，检查系统代理是否已开启。

如果节点无法连接，先更新订阅，再换节点测试。

如果所有节点都不通，检查本机防火墙或安全软件是否拦截 V2RayN。

11. NekoRay 使用教程

NekoRay 是基于 Qt 的跨平台代理客户端，适合需要多协议和图形界面的用户。

安装方法

打开 NekoRay Releases。

下载对应系统版本。

解压或安装后运行。

Windows 用户注意不要把软件放在权限受限目录中。

导入订阅

打开 NekoRay。

进入订阅或分组管理。

添加订阅链接。

更新订阅。

选择节点。

启动代理

开启系统代理。

根据需要开启 TUN 模式。

选择路由模式。

测试访问。

常见问题

如果 TUN 模式无法开启，可能是权限不足。Windows 可以尝试以管理员身份运行。

如果 DNS 异常，可以先关闭高级 DNS 设置，回到默认配置测试。

12. Clash for Windows 汉化版 使用教程

Clash for Windows 汉化版 是旧版 Clash for Windows 的汉化版本，更适合需要兼容旧配置的用户。

安装方法

打开 Clash for Windows 汉化版 Releases。

下载 Windows 安装包。

安装并运行。

导入订阅

进入 Profiles 页面。

在输入框中粘贴订阅链接。

点击 Download。

下载成功后，选择该配置。

启动代理

进入 General 页面。

打开 System Proxy。

需要全局代理时选择 Global。

日常使用建议选择 Rule。

常见问题

如果配置下载失败，检查订阅链接是否支持 Clash 格式。

如果软件版本较旧，建议优先考虑维护更活跃的 Clash Verge Rev 或 Mihomo Party。

五、macOS 客户端教程

13. ClashX 使用教程

ClashX 是 macOS 上常见的 Clash 客户端，适合喜欢菜单栏操作的用户。

安装方法

打开 ClashX Releases。

下载 .dmg 文件。

拖入 Applications 应用程序文件夹。

首次打开时，如果系统提示无法验证开发者，可以在系统设置的安全性与隐私中允许打开。

导入订阅

点击菜单栏 ClashX 图标。

找到配置或 Config 菜单。

选择从 URL 导入配置。

粘贴订阅链接。

下载并切换到该配置。

启动代理

在菜单栏中打开 Set as System Proxy。

选择 Rule 模式。

进入 Proxy 菜单选择节点。

常见问题

如果浏览器没有效果，检查 macOS 系统代理是否被其他软件覆盖。

如果菜单栏没有图标，确认 ClashX 是否已经启动。

14. V2RayU 使用教程

V2RayU 是 macOS 平台的 V2Ray 客户端，适合使用 V2Ray 系配置的用户。原工具清单也把 V2RayU 列为 macOS 客户端。(GitHub)

安装方法

打开 V2RayU Releases。

下载 .dmg 文件。

拖入 Applications。

打开后允许网络权限。

导入订阅

点击菜单栏 V2RayU 图标。

进入服务器订阅设置。

添加订阅地址。

更新订阅。

选择一个节点。

启动代理

开启系统代理。

选择 PAC 或全局模式。

测试网页访问。

常见问题

八、通用排错方法

无论你使用哪个工具，遇到问题时都可以按这个顺序排查。原项目的快速开始指南也建议按“选择客户端、下载安装、导入订阅、配置客户端、测试连接”的流程操作，并在连接异常时检查配置、节点、本地网络和防火墙等因素。(GitHub)

1. 订阅导入失败

先检查：

  • 订阅链接是否复制完整；
  • 链接是否过期；
  • 客户端是否支持该格式；
  • 是否需要先转换格式；
  • 本地网络是否能访问订阅地址。

解决方式：

  • Clash 类客户端使用 Clash/Mihomo 格式；
  • Sing-box 类客户端使用 Sing-box JSON；
  • Surge、Loon、Quantumult X 使用各自兼容格式；
  • 格式不对时使用 subconverter 或 Sub-Store 转换。

2. 连接成功但网页打不开

先检查：

  • 是否开启系统代理或 VPN；
  • 是否选中了可用节点；
  • 是否有其他代理软件冲突；
  • 浏览器是否安装了独立代理插件；
  • DNS 是否异常；
  • 当前模式是否选错。

建议先切换到 Global 测试。如果 Global 能用、Rule 不能用，说明大概率是规则分流问题。

3. 手机后台自动断开

Android 检查：

  • 电池优化；
  • 后台运行权限；
  • VPN 常驻权限；
  • 系统管家限制。

iOS 检查：

  • 是否手动关闭了 VPN；
  • 是否切换网络导致断开；
  • App 是否需要重新授权 VPN 配置。

4. 节点测速全部失败

常见原因：

  • 订阅已经失效；
  • 网络环境不稳定；
  • 客户端内核异常；
  • 防火墙拦截；
  • DNS 解析失败。

可以尝试：

  • 更新订阅；
  • 更换网络；
  • 重启客户端；
  • 换一个客户端测试；
  • 查看日志定位错误。

九、安全提醒

下载客户端时，尽量从官方 GitHub Releases、官方网站或 App Store 获取，不要使用来源不明的安装包。原项目免责声明也提醒，相关工具仅供技术交流和学习使用，使用时应遵守当地法律法规，并注意免费节点和陌生配置可能带来的隐私风险。(GitHub)

建议做到：

  • 不安装破解包；
  • 不使用来历不明的二次打包版本；
  • 不随意导入陌生人发来的配置文件；
  • 不在不可信配置下登录重要账号；
  • 定期更新客户端；
  • 备份自己的配置；
  • 遵守当地法律法规。

十、总结

如果你是新手，优先从 Hiddify Next、Clash Verge Rev、V2RayNG、Shadowrocket 这类容易上手的客户端开始。

如果你需要订阅转换，优先了解 subconverter 和 Sub-Store。

如果你主要使用 Sing-box 生态，可以选择 Hiddify Next、Karing、sing-box VT、sing-box-converter 或 v2sing。

实际使用中，不需要每个工具都安装。最合理的方式是：每个平台保留一个主力客户端，再准备一个订阅转换工具备用。这样既方便管理，也能减少系统代理冲突和配置混乱。
