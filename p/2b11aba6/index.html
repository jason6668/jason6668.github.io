二、🎬 马老师专属直播聚合

地址：https://zb.8818618.xyz/

这是整个生态里功能最全的一个站：把 B站、斗鱼、虎牙、抖音、快手、YY、映客等平台的直播间聚合到一起，不用装一堆 App，一个网页全搞定。

2.1 首页怎么用

  • 顶部是平台 Tab（B站、斗鱼、虎牙、抖音、快手、YY直播、映客直播、体育赛事……），点一下切换平台，左右可滑动
  • 首页有热门推荐轮播，按在线人数自动排最火的 5 个直播间
  • 每个卡片显示封面、标题、主播名、红色 LIVE 角标和观看人数，点卡片直接进播放页
  • 播放页支持线路切换（卡顿时换一条线路）、关注主播（登录后）

2.2 体育赛事 Tab

点「体育赛事」进体育专区：顶部显示在播数量统计，下面按运动项目筛选（足球、篮球、网球、斯诺克、羽毛球、乒乓球、排球、赛车、格斗、高尔夫等），还有四个分组：

  • 官方版权：腾讯体育、咪咕、央视体育 CCTV5 等
  • 主播解说：虎牙/斗鱼/抖音/快手/B站/YY 的体育主播
  • 比分资讯：直播吧、懂球帝、虎扑等
  • 国际源：ESPN、DAZN 等

2.3 分区 / 搜索 / 工具

  • 分区：按游戏/娱乐分类找直播间（比如想看英雄联盟，直接进游戏分区）
  • 搜索：搜主播名或直播间标题，全平台一起搜
  • 工具：站长精选的实用工具合集，马老师专属混淆和马老师专属云终端的入口也在工具页里

2.4 摸鱼中心（隐藏彩蛋）

侧边栏有个 🐟 摸鱼入口，里面有：

  • 💰 薪跳：输入月薪和上下班时间，实时显示「今天已经赚了多少钱」
  • 🐟 摸鱼点击器：连击加成小游戏
  • 🧧 红包雨
  • 🚨 老板键：点一下或按 ~ 键，瞬间切换成假 WPS 表格全屏，再按 Esc 回来

2.5 会员区域

侧边栏「会员区域」需要激活码才能进（激活码找马老师获取）。一码一机，首次使用绑定设备。

2.6 账号

点右下角「我的」→ 注册/登录。这个账号全生态通用（见第 9 节）。

📱 手机访问体验完整：底部 Tab 栏、平台横滑、播放页全屏都做了移动端适配。记得用「请求移动版网站」，不要开「请求桌面网站」。

三、📺 马老师专属TV

地址：https://tv.8818618.xyz/

影视点播 + 电视直播二合一。

3.1 影视点播

  • 首页有热门电影 / 新番放送 / 热门剧集 / 热门综艺四个板块
  • 点进去看详情，有简介、选集、继续观看（自动记住看到哪）
  • 右上角「换源」可以切换视频源（需要在管理后台先配置视频源）

3.2 电视直播

  • 央视卫视：CCTV 各套、地方卫视
  • 环球频道：海外电视台
  • 直连线路，打开即播

3.3 专属音乐入口

TV 首页有「专属音乐」卡片，点进去跳到音乐站（下一节）。

💡 TV 站内嵌在直播站里：在直播站侧边栏点「🎬 影视」也能进，地址会变成 zb.8818618.xyz/ys，是同一个站。

四、🎵 专属音乐

地址：https://music.8818618.xyz/

免费听歌站，浏览器打开就能用，不用装 App。

  • 搜索：跨站曲库检索，搜歌名/歌手
  • 播放：歌词同步显示，切歌无缝
  • 批量管理：可以批量加歌单

音源来自免费 API，仅供学习交流，记得支持正版。

5.2 新手玩法

  1. 注册：右上角注册（需要邀请码的话找老用户要，邀请人得 🍗20 鸡腿；开放注册期间要填图形验证码）
  2. 签到：每天签到领鸡腿（论坛积分），鸡腿能在积分商城换东西
  3. 发帖：选对板块再发，标题支持加前缀标签；编辑器工具栏有「🖼 图片」按钮，发帖回帖都能一键传图
  4. 等级：多发帖、多互动升级，高等级解锁更多权限（比如发帖设阅读权限 LV1-LV10）
  5. 教程：点导航栏「教程」有新手指南，从注册到 Markdown 发帖全讲了

5.3 特色功能

  • 👎 踩：赞踩互斥，踩多的帖子自动沉底

  • 楼层锚点：长帖子里点楼层号直达

  • 👁 只看楼主：只看楼主的回复，追更神器

Q：手机上看哪个体验最好？
A：所有站都做了移动端适配。用 Safari/Chrome 打开就行，记得不要开「请求桌面网站」，用默认的移动版。

Q：直播卡顿怎么办？
A：播放页点「线路切换」换一条线路；或者退出重进（会自动拉取新地址续播）。

Q：论坛鸡腿有什么用？
A：论坛积分，可以在积分商城换东西，也可以给喜欢的帖子打赏。每天签到、发帖、被点赞都能得。

A：全站已换成短链（比如 blog.8818618.xyz/p/abce2187/），分享更方便。旧的长链接已失效。

Q：发了博客，论坛会自动同步吗？
A：会。博客 push 新文章后几分钟内，论坛「博客同步」板块自动发帖（带摘要和原文链接）。
