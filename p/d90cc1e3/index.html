马老师专属聊天使用教程：登录、群聊、频道和树洞投稿

马老师2026-10-042026-10-07

马老师专属聊天使用教程

这是社区系列教程的第二篇，讲社区聊天 chat.688650.xyz 怎么用：怎么登录、群和频道有什么区别、怎么给树洞投稿。先看总教程没看的，建议先看 《社区上新：「忏悔录」正式上线》总教程，把论坛账号注册好。

登录进来之后，聊天长这样（左边是会话列表，右边是消息区，手机上是底部四个标签页切换）：

会话列表放大看是这样：带「频道」标识的是只能看的频道，普通的是可以发言的群和私聊：

一、注册与登录

聊天现在可以自己注册了，打开 chat.688650.xyz/register 就能开户：

  1. 平时是邀请码注册：注册页要填邀请码，没有码注册不了。邀请码找马老师要，拿到后填上即可；有人发你邀请链接的，点链接打开就是带码的注册页，少填一步
  2. 开放注册期间免码：马老师不定期开放免注册码窗口，窗口内邀请码可以不填（注册页会显示「🎉 开放注册中」），窗口一关就恢复要码
  3. 注册完回登录页，用刚注册的用户名密码登录，进来就是上面截图的样子

密码忘了找管理员重置。

二、界面怎么看

  • 左边/底部第一个标签：消息——你加入的所有群、私聊、频道都在这里，有新消息的会排在上面并带红点
  • 通讯录：找人、发起私聊从这里进
  • 动态：类似朋友圈，发文字和图片；发的时候可以选「同步到论坛」，动态会同时出现在论坛的聊天动态里
  • 我的：改昵称、头像，看收藏

「我的」页长这样：你的数字 ID 在这里看（加好友、被人 @ 时用），新建群组/频道、我的收藏、设置也都在这一页：

三、群、频道、私聊的区别

  • 私聊：和一个人单独说话
  • 群聊：大家都能发言的聊天室。点会话右上角能看成员列表和群设置，管理员可以设置慢速模式（发言间隔）和成员权限
  • 频道：只有管理员发言的公告型会话，比如「树洞」频道。你只需要看，不用回复；内容是受保护的，不能转发出去

发错了消息不用慌：自己发的消息 24 小时内可以撤回——长按（手机）或右键（电脑）点那条消息，选「撤回」。图片和文件可以直接把文件拖进输入框发送。

点开一个会话就是这样，底部输入框打字发送：

点输入框旁边的表情按钮，Emoji、表情包、GIF 动图三个页签，点一个直接发：

四、用聊天给树洞投稿（重点）

  1. 在会话列表里找到「🌳 树洞投稿」机器人，点进去私聊它
  2. 按它的提示选「我要投稿」
  3. 选实名或匿名（匿名发表后不显示你的任何信息）
  4. 把内容发过去，可以带图片
  5. 提交后等管理员审核，通过后会出现在树洞频道和论坛的忏悔录里

投稿规则和论坛是一套：带广告、带引流链接的过不了审。详细的投稿说明看 总教程的第五节。

五、常见问题

为什么我进不了某个群？
群是邀请制的，没被拉进去就看不到。找群主或管理员拉你。

频道为什么不能发言？
频道就是只看的，管理员发布、大家阅读，想讨论去对应的群里。

消息发出去对方没收到？
先刷新一下页面；还是不行截个图发给管理员看。

六、2026-10-07 新功能

群管中心（群主、管理员、子管理员可用）：进群点群名打开群资料页，点「打开群管中心」。违规词、链接、名片、刷屏自动拦截，警告、禁言、踢人、黑名单/白名单都在这里；也能直接在聊天里发指令，比如 @某人 警告、@某人 禁言3天。

个人二维码：「我的」页你的 ID 旁有二维码按钮，点开是带头像和 @用户名的专属码，可保存图片或复制链接发出去；别人扫这个码直接打开你的小卡加好友，不用再报数字 ID。

扫一扫：会话列表顶部和「我的」页都有入口。扫本站的个人码或群邀请码会自动加好友/进群；扫到站外链接会先弹确认，不会直接打开。（下图是电脑浏览器没有摄像头时的画面，手机上打开就是摄像头取景，也能从相册选图识别。）

会话分组：会话列表上方点「＋」新建分组，再长按会话选「移动到分组」归类，每个会话只归一个组。注意：分组只存在当前这台设备上，换手机或清缓存就没了。

长按菜单与大表情动画：长按（手机）或右键（电脑）任意一条消息会弹出菜单（毛玻璃效果，电脑上是消息上方的悬浮工具条）；单独发一个大表情时，表情会带弹跳动画出现。

薄荷青主题：设置页的主题列表新增「薄荷青」一款，全站共 41 款主题，选上后是薄荷绿渐变背景。
